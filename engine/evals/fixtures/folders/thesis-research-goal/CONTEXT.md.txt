# Thesis experiments (synthetic)

## What this is
Experiments for an honours thesis on guarding LLM agents against unsafe tool calls. Code lives in this repo.

## Current state
- `run_pilot.py` runs the pilot benchmark (5 tasks); 3 tasks pass, 2 crash on tool timeouts.
- `guard/policy.py` holds the rule-based guard; `guard/scorer.py` scores each episode.
- `analysis/plot_results.ipynb` makes the comparison plots (only covers the pilot).
